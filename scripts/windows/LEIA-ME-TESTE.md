# Dita.se no Windows 11 x64

## Primeira instalação

1. Baixe o arquivo `Dita.se-windows-x64-<versão>-setup.exe` pelo link enviado pelo Dev Founder. Salve o arquivo.
2. Abra o PowerShell, digite `Get-FileHash -Algorithm SHA256 -LiteralPath ` (com um espaço no fim), arraste o arquivo baixado para a janela e aperte Enter.
3. Compare o valor da coluna **Hash** com os 64 caracteres que o Dev Founder enviou pelo chat. Se algum caractere estiver diferente, pare e avise.
4. Se a soma conferir, abra o instalador pelo Explorador de Arquivos. Ele instala para o seu usuário. Se o Windows impedir a abertura, envie ao Dev Founder a mensagem exibida.

## Atualizações e desinstalação

O app procura atualizações quando abre e pede confirmação antes de instalar. Para reinstalar manualmente, encerre o Dita.se pelo ícone da bandeja e repita o procedimento acima com a versão e a soma confirmadas pelo Dev Founder. Para remover o app, vá a **Configurações > Aplicativos > Aplicativos instalados**, procure **Dita.se** e escolha **Desinstalar**. A desinstalação padrão preserva os dados.

## Relatório de teste

No app, abra **Ajustes** e clique em **Copiar relatório de teste**. Cole na conversa com o Dev Founder.
